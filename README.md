# Smart Home Tech System

Комплексная система умного дома, включающая телеметрию, коммерческие сервисы и инфраструктурные компоненты.

## Архитектура проекта

Проект состоит из нескольких основных модулей:

### Telemetry (Телеметрия)
Система сбора, анализа и агрегации данных от устройств умного дома:
- **Collector** - собирает события от устройств и отправляет в Kafka
- **Analyzer** - получает Кафка события и запускает сценарии автоматизации. Работает с БД и gRPC клиентом.
- **Aggregator** - агрегирует данные и формирует снимки состояния
- **Serialization** - содержит схемы данных в формате Protobuf и Avro для сериализации сообщений

### Commerce (Коммерческие сервисы)
Система электронной коммерции для управления товарами и заказами:
- **Shopping Store** - каталог товаров умного дома (освещение, датчики, контроллеры)
- **Shopping Cart** - корзина покупателя
- **Order** - управление заказами
- **Payment** - обработка платежей
- **Delivery** - логистика и доставка
- **Warehouse** - управление складскими запасами
- **Interaction API** - общий API для всех бизнес сервисов

### Infra (Инфраструктура)
Инфраструктурные сервисы:
- **Config Server** - централизованное управление конфигурациями
- **Discovery Server** - централизованное управление адресами сервисов
- **Gateway** - API шлюз

## Технологический стек

- **Java 21** - основной язык программирования
- **Spring Boot 3.3.2** - фреймворк для создания микросервисов
- **Apache Kafka** - система обмена сообщениями для телеметрических данных
- **PostgreSQL** - реляционная база данных
- **Docker Compose** - оркестрация контейнеров
- **Protobuf** - формат сериализации данных для gRPC
- **Avro** - формат хранения структурированных данных для Apache Kafka
- **gRPC** - межсервисное взаимодействие

## Схема данных

Система использует два формата схем данных:

### Protobuf
Используется для gRPC взаимодействия между сервисами:

**HubEventProto** - события, связанные с хабом умного дома:
- Добавление/удаление устройств
- Создание/удаление сценариев автоматизации
- Типы устройств: датчики движения, температуры, освещенности, климата, переключатели
- Типы условий для сценариев: движение, освещенность, температура, влажность, CO2
- Типы действий: активация, деактивация, инверсия, установка значения

**SensorEventProto** - события от датчиков:
- Датчик движения: качество связи, наличие движения, напряжение
- Температурный датчик: температура в °C и °F
- Датчик освещенности: уровень освещенности и качества сигнала
- Климатический датчик: температура, влажность, уровень CO2
- Переключатель: состояние (включен/выключен)

### Avro
Используется для сериализации сообщений в Apache Kafka:

Система использует Avro для сериализации данных в Kafka топики. Есть три основных топика:

**telemetry.sensors.v1** - события от датчиков умного дома
**telemetry.snapshots.v1** - снимки состояния системы (агрегированные данные)
**telemetry.hubs.v1** - события, связанные с хабами умного дома

Сериализация реализована через:
- `GeneralAvroSerializer` - общий сериализатор для Avro сообщений
- `BaseAvroDeserializer` - базовый десериализатор для Avro сообщений

Avro схемы хранятся в .avdl файлах, и Java-классы генерируются из этих схем в процессе сборки, чтобы обеспечить типобезопасность и возможность эволюции (совместимости) данных.

**HubEventProto** - события, связанные с хабом умного дома:
- Добавление/удаление устройств
- Создание/удаление сценариев автоматизации
- Типы устройств: датчики движения, температуры, освещенности, климата, переключатели
- Типы условий для сценариев: движение, освещенность, температура, влажность, CO2
- Типы действий: активация, деактивация, инверсия, установка значения

**SensorEventProto** - события от датчиков:
- Датчик движения: качество связи, наличие движения, напряжение
- Температурный датчик: температура в °C и °F
- Датчик освещенности: уровень освещенности и качества сигнала
- Климатический датчик: температура, влажность, уровень CO2
- Переключатель: состояние (включен/выключен)

## Запуск проекта

Проект запускается с помощью Docker Compose, который поднимает:
- Kafka кластер
- PostgreSQL базы данных для всех сервисов
- Все микросервисы проекта
